LifeXash: personal productivity app

A daily planner, tagged notes and a mood journal in one app, with a dashboard that shows today's completion score, a productivity streak and a 7-day mood trend.

  • 26 REST API endpoints in FastAPI, organised into routers, services and models.
  • JWT login with bcrypt password hashing. Every query is scoped to the logged-in user, and other users' records return 404.
  • 6 MySQL tables with SQLAlchemy 2.0 and Alembic migrations. Deployed on Render with a TiDB Cloud database over verified TLS.
  • 30+ pytest unit tests and step-by-step test checklists for auth, access control and time zones.
  • Found and fixed a SQL bug where the dashboard showed 1 completed task instead of 3.
  • Installable PWA with an offline banner and update prompt, tested on an Android phone.
